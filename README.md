# Virginia Marc — Personal Portfolio

A modern, responsive personal portfolio built with **React** and **Tailwind CSS**, featuring custom UI components, smooth animations, and a fully functional contact form. Designed to showcase development work, skills, and projects with a clean, cinematic aesthetic.

---

## 🚀 Features

- Fully responsive layout  
- Custom React components  
- Tailwind CSS styling  
- Smooth animations and transitions  
- Dynamic contact form with validation  
- Project sections with clean UI  
- Modern, minimal, and accessible design  

---

## 🛠️ Tech Stack

- **React**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **React Icons**
- **Framer Motion** (optional for animations)
